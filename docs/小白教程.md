# 不会编程？让 Codex 帮你把抖音收藏变成知识库

**你需要具备的：** 会用电脑、有抖音账号。
**不需要的：** 编程基础、看得懂代码。

全程你只需要**复制粘贴几段话**给 AI，剩下的它来做。

---

## 这个工具能干什么

你是不是也这样：刷到有用的视频就收藏，几百条了，但真遇到问题时——**完全想不起收藏过什么，更找不到在哪**。

因为视频的干货全在**语音**里。标题只有一句「9021 Codex太强了…」，你搜「怎么写提示词」根本搜不到。

这个工具会：

1. 把你收藏的视频全抓下来
2. 用 AI 把每条视频的**语音转成文字**
3. 按「**我遇到什么问题会用到它**」重新分类
4. 生成两个网页：一个能全文搜索，一个像目录一样浏览

之后你想找「装修要注意什么」，搜一下，几百条里立刻定位到相关的那几条，还能看到人家具体说了什么。

---

## 准备工作（10 分钟）

### 第 1 步：装 Codex

Codex 是一个 AI 编程助手，能直接在你电脑上帮你干活。

打开「终端」（在「启动台」里搜 `终端` 就能找到），复制这行进去按回车：

```
npm install -g @openai/codex
```

> 如果提示 `command not found: npm`，说明缺 Node.js。
> 去 https://nodejs.org 下载安装（选左边的 LTS 版本），装完重开终端再试。

装好后输入 `codex` 回车，按提示登录即可。

### 第 2 步：装 Chrome

如果还没有，去 https://www.google.com/chrome 下载安装。工具需要用它登录抖音。

---

## 开始搭建

### 第 3 步：建个文件夹

在「文稿」里新建一个文件夹，命名为 `抖音知识库`。

### 第 4 步：让 Codex 进入这个文件夹

打开终端，输入 `cd ` （**cd 后面有个空格**），然后把刚才的文件夹**拖进终端窗口**，按回车。

再输入 `codex` 回车，Codex 就在这个文件夹里待命了。

### 第 5 步：把下面这段话，原样发给 Codex

> 我想搭建一个「抖音收藏知识库」工具，把我的抖音收藏视频转成可搜索的文字库。我不懂编程，请你帮我完整搭建好，每一步用大白话告诉我要做什么。
>
> **功能需求：**
> 1. 自动抓取我抖音收藏夹里的所有视频（标题、链接、话题标签）
> 2. 下载每条视频的音频，用 AI 转成文字
> 3. 按「我将来遇到什么需求会来找它」给视频分类，不要按话题分类
> 4. 生成两个可以双击打开的网页：一个能全文搜索所有文案，一个是分类目录方便浏览
>
> **技术要求：**
> - 用 Python，语音识别用 faster-whisper 的 small 模型（本地跑，不花钱）
> - 抓取用 Playwright 连接我自己登录的 Chrome（抖音风控严，必须用真实浏览器）
> - 下载音频用 yt-dlp
> - 语音模型从 https://hf-mirror.com 国内镜像下载，直接用 curl 下到本地目录再加载，不要用 huggingface_hub 自动下载（会失败）
> - 全流程要能断点续跑，中断了再运行能接着来，不重复
>
> **重要细节（这些是踩过的坑）：**
> - 抖音收藏页是内嵌滚动容器，不是整个窗口在滚，要先找到真正滚动的那个元素
> - 下载失败时 yt-dlp 会报「Fresh cookies needed」，但真实原因通常是作品已被删除。要调抖音的 aweme/detail 接口确认真实原因
> - 同一个接口能拿到视频时长，下载前先检查，超过 40 分钟的超长视频直接跳过
> - 已失效的视频记录下来，以后不再重试
> - 英文关键词匹配要用词边界，否则 skill 会误匹配 skillful
>
> **做成两个双击就能运行的 .command 文件：**
> - 第一个：抓取收藏 + 分类（需要我手动登录抖音并进入收藏页）
> - 第二个：转写 + 生成网页，要在后台运行，我可以直接关掉窗口
>
> 请先告诉我整体方案，然后一步步实现。遇到需要我操作的地方（比如登录抖音），明确告诉我该做什么。

发完等它干活。**它会边做边问你，照着回答就行。**

## 过程中会遇到什么

### Codex 问你要不要安装东西

会看到类似提示：

```
Do you want to run: brew install ffmpeg?
```

回答 `yes` 或按提示确认。这是在装音频处理工具，必需。

### 让你登录抖音

Codex 会打开一个 Chrome 窗口。你需要：

1. 在这个窗口里登录抖音（扫码即可）
2. 点进「我的收藏」→「视频」
3. 回到终端按回车

> ⚠️ 这一步必须你亲自操作，因为抖音的登录有风控，AI 代替不了。
> 这个 Chrome 窗口是专用的，不影响你平时用的浏览器。

### 下载语音模型

会下一个约 460MB 的模型文件，等几分钟。**只需要下一次**。

### 开始转写

这一步最久。**每条视频大概 30 秒到 2 分钟**：

- 100 条 → 约 2 小时
- 700 条 → 约 18 小时

可以让它挂着跑，电脑别休眠就行（系统设置 → 锁定屏幕 → 关闭显示器后不休眠）。

## 卡住了怎么办

**最重要的一条：把报错原样复制给 Codex，它会自己修。**

不用看懂报错，整段贴进去，加一句：

> 报错了，帮我看看：
> （粘贴报错内容）

### 常见情况

| 现象 | 跟 Codex 说 |
|---|---|
| 提示 `command not found` | 「提示 xxx 命令找不到，帮我装一下」 |
| 一直转圈没反应 | 「卡了很久没动静，帮我看看卡在哪」 |
| 只抓到几条就停了 | 「只抓到 N 条，我收藏了几百条，帮我看看为什么」 |
| 转写出来是乱码 | 「转写结果是乱码，帮我检查一下语言设置」 |
| 关掉窗口后任务停了 | 「关掉终端后后台任务停了，帮我改成 nohup 加 disown 真正后台运行」 |

## 做完之后

文件夹里会出现 `outputs` 文件夹，里面有：

**收藏文案.html** — 双击打开
- 顶部搜索框，输入任意关键词，**标题和视频里说的话一起搜**
- 点任意一条展开完整文案
- 有「复制文案」「显示时间轴」按钮

**收藏脑图.html** — 双击打开
- 左边是分类目录，点开看该类所有视频
- 每张卡片有绿色标签标明类型（保姆级教程 / 避坑经验 / 工具推荐…）

**收藏文案.csv** — 用 Excel 打开，方便自己整理

## 日常使用

以后每隔一段时间，双击那两个 `.command` 文件就行：

1. **1-抓取收藏.command** — 只抓新增的（遇到抓过的会自动停），几分钟
2. **2-转写出稿.command** — 只转新的，然后更新网页

新收藏了 20 条，大概 20 分钟就更新完。

---

## 想改点什么

直接跟 Codex 说人话就行：

> 「AI 编程」这个分类太大了，帮我拆细一点

> 我想加一个「露营装备」分类，把相关视频归进去

> 网页字太小，帮我调大一点

> 能不能加个按时间排序

> 我想把结果同步到飞书多维表格

它会改代码然后重新生成，通常几十秒。

---

## 几个提醒

- **只整理自己的收藏**，别去抓别人的内容
- **转写在你自己电脑上完成**，视频内容不会上传到任何地方
- **第一次跑会很久**，之后增量更新很快
- **中途可以停**，下次接着跑，不会重复
